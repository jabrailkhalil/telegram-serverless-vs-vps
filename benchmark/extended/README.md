# Расширенные замеры, 17 октября 2026

Основной документ: [report.md](report.md). Готовые агрегаты: [summary.json](results/summary.json) и [metrics.csv](results/metrics.csv). Числа для статьи берутся только из consolidated.json, где записано происхождение каждой группы.

## Фазы выполненного эксперимента

1. collect.mjs собрал SQL-микротесты, чистый JavaScript и масштабирование журнала. Завершённые части сохранены в raw.json. При исследовании обнаружены ограничение массового запроса и HTTP 429 у developer API; промежуточные сегменты сохранены отдельно.
2. finish.mjs повторил **все** финальные операции с базой VPS на постоянном ext4, затем собрал ограниченную SQL-конкуренцию, исходящий HTTP и отдельные пустые вызовы. Данные в supplement.json.
3. query-boundaries.mjs проверил SQL-границы в отдельных таблицах, подтвердил их удаление, сохранность 18 поливов настоящего сада и неизменность опубликованного кода.
4. consolidate.mjs выбрал финальные фазы. summarize.mjs пересчитал nearest-rank квантили и флаги корректности.

Данные raw.json на VPS изначально получены в /tmp: в Финляндии это RAM. Их DB-тайминги не входят в окончательный набор. Текущий сборщик для будущих повторений уже создаёт базу в /var/tmp и отказывается от tmpfs. Добавлен режим --core-only, который пропускает старую прерванную проверку независимых вызовов developer API. finish.mjs использует один облачный вызов для параллельных SQL-запросов. Это уточнения управления стендом, SQL и вычислительные задачи сохранены.

## Повторение

Запускать на своей отдельной копии тестового сада с применённой схемой. Нужны локальный Node.js, @tgcloud/cli 0.2.0, два Linux VPS с SSH-доступом и переносимый **Linux** Node.js 22.23.3 с node:sqlite. Скрипты используют внутренний API указанной версии CLI.

Подготовьте вне публикуемой папки SSH-config с псевдонимами fi и de, путями к своим ключам и проверкой known_hosts. CLI авторизуется через npx tgcloud login в папке проекта либо принимает уже существующую TGCLOUD_TOKEN из окружения. Значение токена не записывается в результаты.

Пример переменных PowerShell, все значения ниже являются путями к собственным локальным файлам:

```powershell
$env:BENCH_WORK_DIR = 'C:/private/garden-benchmark-work'
$env:BENCH_SSH_CONFIG = 'C:/private/ssh-config'
$env:BENCH_NODE_LOCAL = 'C:/private/node-linux-22.23.3'
$env:TGCLOUD_CLI_ROOT = 'C:/path/to/node_modules/@tgcloud/cli/src'
node benchmark/extended/collect.mjs --core-only
node benchmark/extended/finish.mjs
node benchmark/extended/query-boundaries.mjs
node benchmark/extended/consolidate.mjs
node benchmark/extended/summarize.mjs
```

Команды приведены для корня распакованного проекта. Они заменяют результаты текущей папки; для своего повторения сделайте копию комплекта. В приватной рабочей папке сохраняется исходный снимок ревизии для проверки неизменности. Облачные обращения разнесены паузами, HTTP 429 повторяется с учётом retry_after; квота developer API всё равно может прервать фазу. Ошибочный или незавершённый прогон нельзя выдавать за полный, consolidate.mjs проверяет целостность финальных фаз.

Для независимого пересчёта уже приложенных результатов достаточно последних двух команд, доступы к серверу и Telegram им не нужны.

## Что именно измеряется

- Микро-SQL: 3 серии по 50 измерений; запись 32 строк: 3 по 10; 3 прогрева каждой серии исключены.
- Сад: 1000, 10 000 и 100 000 исходных записей, 3 серии. Чтение: 30 измерений, полив: 20, после 3 прогревов. Ошибки 100 000 строк Telegram сохраняются отдельно, квантилей для них нет.
- CPU: 30 блоков по 20 повторений. JSON: 30 блоков по 5 повторений. Время всего блока делится на число повторений; p95 относится к распределению средних блока. Нулевой внутренний Date.now облака для чистого JS не используется как реальное время.
- SQL-конкуренция: 1, 4, 8, по 5 раундов чтения/записи. Telegram: Promise.all внутри одной функции; VPS: независимые соединения workers. Счётчик обязан стать 65. Это не пользовательский RPS.
- Исходящий HTTP: 2 адреса, до 30 попыток каждого на среду, остановка после 3 последовательных ошибок в раунде. Успешные и неуспешные времена не смешиваются.
- Пустая функция: 10 независимых вызовов. Время developer API не является временем отображения ответа в Telegram.

Модель сада берётся из tgcloud/lib/model.js, адаптеры в cloud.js и vps-runner.mjs. Изменённый вариант gardenReadNoEnsure существует только в тестовой копии. Настоящий опубликованный сад не оптимизировался и не передеплоился.

Адреса VPS, SSH-конфигурация, ключи, CLI-токен и приватный снимок ревизии в комплект не входят. Локальные результаты содержат только синтетические данные benchmark и число поливов настоящего сада.
